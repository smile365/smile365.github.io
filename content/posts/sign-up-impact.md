## 前言

Impact.com 是一个做联盟营销（Affiliate Marketing）的平台，说白了就是中间人：品牌方把推广任务挂上来，推广者（Partner/Publisher）申请通过之后拿到自己的专属链接，别人顺着你的链接下了单，你就能抽一笔佣金。

这套玩法国内叫淘宝客、京东联盟，Impact 上全是海外品牌，Shopify 独立站、SaaS 工具、跨境电商这些居多，客单价和佣金比例都比国内联盟好看一些。

## 为什么要注册

手里有流量就想办法变现，这是最顺的一条路。

*   **博客/独立站站长**：写测评、写教程，文中插几个专属链接，读者点出去买了就有钱，不用自己备货发货。

*   **做自媒体的**：YouTube、TikTok、小红书、公众号，只要内容有垂直属性（数码、美妆、家居、健身），品牌方愿意投。

*   **顺手薅一把**：哪怕暂时不指望它赚钱，先把账号养着，后面有活动了不至于干瞪眼。

我自己在做独立站和这个博客，正好顺手把流程走一遍，记录一下注册时踩到的点。

## 准备材料

1.  一个能正常收信的邮箱（gmail、outlook 都行）；

2.  能访问境外网络的梯子，注册和后台都绕不开；

3.  你自己的网站地址、社交账号，**都要是真实能打开的**，后面会验证；

4.  收款渠道，Payoneer 或者海外银行卡，这一步注册时不用填，但别拖太久。

## 注册步骤

### 1. 打开注册页

参考 [官方网站](https://help.impact.com/partner/zh/ni-xiang-liao-jie-shen-me/getting-started/readme-1/im-a-creator/step-1-work-with-brands) 注册账号，右上角可以切换语言，有简体中文。

![enter description here](https://cdn.sxy21.cn/static/imgs/1791526651451.png)

邮箱、Apple、Facebook、Google、X、LinkedIn 都能注册。建议直接用邮箱，第三方登录省不了后面补资料的步骤。

### 2. 填写账号信息

![enter description here](https://cdn.sxy21.cn/static/imgs/1791526829505.png)

名字、姓氏按护照拼音写，后面提现的时候要跟收款账户一致，别乱填。用户名自己想一个，手机号 +86 是可以的。底部两个协议必须勾上。

### 3. 业务分类

![enter description here](https://cdn.sxy21.cn/static/imgs/1791526874214.png)

这一步是告诉品牌方"你是谁、你的受众为什么来看你"，直接影响后面哪些品牌会来找你。几个选项的区别：

| 分类 | 适合谁 |
| --- | --- |
| 社交媒体网红 | 受众是来看你这个人、你的内容的（抖音/小红书/YouTube 博主） |
| 内容/评测媒体 | 受众是来查产品信息、找购买决策依据的（测评站、导购博客） |
| 忠诚消费奖励/返利 | 做返现、积分奖励站的 |
| 优惠/优惠券 | 做 coupon、折扣码站的 |

个人博客和独立站一般选**内容/评测媒体**，我选的这个。

### 4. 宣传渠道

![enter description here](https://cdn.sxy21.cn/static/imgs/1791526947216.png)

网站、社交、移动应用、播客、邮件通讯、离线，能勾的全勾上，后面还能补。

**注意**：网站、社交账号、移动应用等都需要真实，会验证。填一个打不开或者跟你对不上的地址，卡在这里就很麻烦了。

### 5. 账户详细信息

![enter description here](https://cdn.sxy21.cn/static/imgs/1791527145243.png)

到这一步页面顶部的 logo 变成了 spaceship，别慌，Impact 现在用的是 Spaceship 的账号体系，是正常的。

账户名称个人就写姓名，有公司就写公司名。**货币这一项想清楚再点确认**，弹窗写得很明白：进入下一步之后无法更新。国内个人一般就是 CNY，如果收款走 Payoneer 的美元账户，那就选 USD，选错了只能重新开号。

### 6. 介绍一下你自己

![enter description here](https://cdn.sxy21.cn/static/imgs/1791527321355.png)

![enter description here](https://cdn.sxy21.cn/static/imgs/1791527431708.png)

三个下拉框的逻辑：

*   **I am**：creator（创作者，为品牌做宣传）／publisher（出版商，拥有网站或应用并靠它变现）／agency（代理机构，替别人管理推广）。
*   **operating as**：个人就选 an individual。
*   **who promotes primarily through**：主要靠什么渠道推，网站选 website(s)。
*   **where I provide**：你提供什么形式的内容，博客选 editorial content。

这里 creator 和 publisher 有点容易纠结。判断标准很简单：你主要是靠"人"接广告（自己有粉丝、品牌找你拍内容）就是 creator；你主要是靠"站"赚钱（流量来自搜索、内容里挂链接）就是 publisher。我这种写博客的，前面业务分类选了内容/评测媒体，这里选 publisher 更贴一些。

### 7. 连接渠道

![enter description here](https://cdn.sxy21.cn/static/imgs/1791527461584.png)

左侧进度条走到这里就 50% 了，支持的渠道比前面那一步细得多：Instagram、TikTok、YouTube、X、Facebook、Website、Pinterest、LinkedIn、微信、微博、Twitch、Substack、Email/Newsletter、Podcast、移动应用、浏览器插件等。

![enter description here](https://cdn.sxy21.cn/static/imgs/1791527970477.png)

页面顶上有句话：**连结相关管道以加快核准速度，品牌会优先考虑拥有已连结管道的合作夥伴**。所以这一步不是可选项，尽量把网站连上。

以新增网站为例，填好域名之后要验证网站所有权，下拉里选验证方式，我用的 Meta 标签这一种：复制那行 `<meta name='impact-site-verification' value='...'>`，贴到网站首页 `<head>` 里，再点新增网站就会执行验证。

顺便说下 Hugo 站怎么加。主题模板里一般没有预留自定义 head 的口子，我是直接在主题的 `layouts/partials/head.html` 加了一行，由 config 参数驱动，以后换验证串只改配置：

```go-html-template
{{ with .Site.Params.impact_verification }}<meta name='impact-site-verification' value='{{ . }}'>{{ end }}
```

```toml
[params]
  impact_verification = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

提交部署之后 `curl` 一下首页，确认标签真的在 `<head>` 里，再回后台点验证。

## 注册之后

账号建好只是开始，后面大概这么几件事：

1.  在 Marketplace 里挑品牌申请合作，每个品牌单独审，看它给的佣金结构和素材要求；
2.  拿到自己的追踪链接，放进文章内容里；
3.  过一段时间回后台看报表，哪些链接出单了、转化率多少，再决定往哪类内容上加码。

品牌方也可能主动发邀请过来，这种通过率比自己去申请高不少，具体看 [品牌邀请注册](https://help.impact.com/partner/zh/ni-xiang-liao-jie-shen-me/getting-started/zai-pin-pai-yao-qing-ni-hou-zhu-ce)。
